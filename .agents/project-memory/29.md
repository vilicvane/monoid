# iOS 核心取舍与真机确认

- **NFC 交互**：Core NFC 有系统面板和会话时限。读卡前解锁已保存的 Access PIN，结束读卡后才输入 PIN 或保存凭据；错误时关闭系统面板，由用户重新发起。退出前台也终止当前扫描，超时或回到前台不自动重放安装、修改 PIN 或签名操作。AID 白名单来自当前 applet bundle 和两个 GlobalPlatform 管理器；固件升级改变 AID 时要同步更新。
- **凭据保护**：每个显式 scope 一次 Face ID/Touch ID，最长 60 秒，后台或锁屏撤销；凭据限本机并绑定当前生物识别集合。接受 Keychain 将失效项表现为不存在、卸载后可能残留的边界；继续支持手动输入 PIN，不降低保护等级来规避失败。
- **真机仍需确认**：选择带 NFC Tag Reading 权限的 Apple 签名团队后，在 iPhone 上跑卡片安装/读写/签名、取消/超时、相机首次授权与旋转裁切、生物识别集合变更。模拟器无法证明射频通信或 Secure Enclave 行为；尤其 GlobalPlatform 管理器 `A000000003000000` 的实际 Core NFC 接受情况需要实卡确认。
