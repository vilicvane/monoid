# Dependency audit fixes

## Request

[user] After a dependency audit of all four npm lockfiles, approved the
low-risk fixes: remove unused dependencies, update within existing ranges and
bump wrangler/miniflare. Replacing `@ionic/cli`, Capacitor 8.6 and the
ESLint/`@mufan/eslint-plugin` major upgrade were not part of the approval.

## Changes

[agent]

- Removed unused root dependencies: `@ionic/react-router`, `react-router`,
  `react-router-dom` and their `@types`, `jotai`, `tslang`,
  `@vitejs/plugin-legacy`, `run-in-every` and `@capacitor/dialog`. Native
  plugin lists were regenerated with `npx cap update`. Keep `@capacitor/haptics`
  (Ionic components call it implicitly) and `@capacitor/status-bar` (configured
  in `capacitor.config.ts`).
- `classnames` is used: imports spell it `'classNames'`, which resolves on
  case-insensitive file systems (the Authority login page aliases it).
  Search case-insensitively before calling a package unused.
- Vite 7.0.6 → 7.3.7 for the dev-server advisories (arbitrary file read over
  the WebSocket, Windows `server.fs.deny` bypasses), which matter because
  live reload exposes the server on the LAN. Record 99's contract was
  rechecked: the `vite-hmr` transport, the `vite:ws:disconnect` path and the
  server payload types are unchanged; only Vite's fallback ping moved into a
  SharedWorker, which the wrapper does not touch. The reconnect plugin is now
  enabled for exactly 7.3.7.
- Held back:
  - `styled-components` `~6.3.12`. 6.4.0 drops its unused `postcss`
    dependency but tightens polymorphic `as` typing, which breaks the
    dynamic-`as` call sites in `expandable-key-group.tsx` and `@key-item.tsx`.
    `postcss` is not in the bundle, so the remaining advisory is nominal.
  - Prettier `3.6.2`: 3.9 reformats union types in about 100 files.
- The Authority login page dedupes `react`, `styled-components`,
  `@ionic/react`, `mobx` and `mobx-react-lite`, but typechecks shared app
  components against the app's copies. Keep its exact pins equal to the app's
  resolved versions, or `npm run build` there fails.
- Workers: wrangler 4.156.0, miniflare 5.20261023.3-beta (the version wrangler
  bundles, with undici 7.30.1), `@cloudflare/workers-types` 5.20261101.1
  (wrangler's peer). npm audit's suggested miniflare 4.x "fix" is a downgrade.

## Remaining advisories

- `@ionic/cli` (no upstream fix; `tar`, `basic-ftp`, `proxy-agent` chain) is
  used only by `npm run android`. Capacitor's own `cap run` live reload
  (`--live-reload`, `--host`, `--port`) could replace it, with Vite started
  separately.
- ESLint 8 / `@typescript-eslint` 6 (`minimatch`, `brace-expansion`) needs
  `@mufan/eslint-plugin` 0.3.
- `@capacitor/cli` `uuid`/`xcode` needs Capacitor 8.6.0.
- The Authority login page's `@reown/appkit` 1.8.24 (latest) pins `zod` 3,
  which has no fixed release.

## Validation

Root build, ESLint, Prettier and 3552 app tests; Authority worker unit and
runtime tests; the login page build and tests; gas-history tests, lint and
deploy dry run. The dev server was checked live with the plugin active.
Reconnect on a phone was not repeated.
