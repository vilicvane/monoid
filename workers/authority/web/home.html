Monoid Authority

An optional authority for your Monoid cards

Monoid Authority is operated by Monoid. It is an optional service for the Monoid app, which works with Java Card wallet cards.

The service issues authority bundles to Monoid cards. A bundle can be owned by a Google account, a GitHub account or organization, or an Ethereum wallet. Cards in the same bundle can exchange data with one another.

It also signs time proofs used by cards for one-time passwords (OTP).

Start sign-in from the Monoid app when you choose to use this service. No sign-in is needed to read about it here.
